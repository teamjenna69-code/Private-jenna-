# Jenna Ortega Fandom — Full Static Website

This is a complete responsive static website starter for an **independent, unofficial fan community**.

## Included
- Home, About, Gallery, Filmography, News, Membership, Contact and Privacy pages
- Responsive mobile navigation
- Browser-local fan gallery (images stay in the visitor's browser)
- Working demo membership/contact forms
- No payment processing
- No claim of official affiliation

## Put it online with GitHub Pages
1. Create a GitHub repository.
2. Upload every file and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under deployment, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide your Pages address.
7. For a custom domain, add it under **Settings → Pages → Custom domain** and follow GitHub's DNS instructions at your domain registrar.

## Making forms truly live
The included forms intentionally do not send or store personal information on a server. For production, connect them to a legitimate form service or your own secure backend and update the Privacy Policy accordingly.
